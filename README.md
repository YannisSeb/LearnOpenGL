# LearnOpenGL

This repository is for learning OpenGL with C++. It contains a small Visual Studio project that sets up an OpenGL window and demonstrates basic rendering with vertex buffers, index buffers, vertex arrays, and shaders.

## Requirements

- Windows
- Visual Studio 2022 with the C++ desktop development workload

The project uses GLFW and GLEW, included under `dependencies/`.

## Build and run

1. Open `OpenGL.sln` in Visual Studio.
2. Select a configuration and platform supported by the solution.
3. Build and run the `OpenGL` project.
